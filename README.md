The most honest status page line an AI agent writes while every server is down: plain, first person, specific about what is down, and honest about what it cannot check or does not yet know. No invented cause, no ETA.

## Run it

```sh
node main.ts
```

It writes the single line (156 characters) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
